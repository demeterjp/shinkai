# AGENTS.md

Guidance for AI coding agents working in this repo.

## Project

Shinkai – Expo (React Native) app that trains typing Japanese kana on the flick keyboard. TypeScript, Expo Router, AsyncStorage. Offline, no backend, no accounts.

## Layout

- `src/app/` – screens (Expo Router file-based routes, `_layout.tsx` is the root)
- `src/kana.ts` – kana data and flick keyboard layout
- `src/storage.ts` – AsyncStorage persistence
- `src/theme.ts` – colors / theme
- `src/Screen.tsx` – shared screen wrapper
- `assets/images/` – icons and splash

## Commands

- `npm install` – install deps
- `npx expo start` – dev server
- `npx tsc --noEmit` – typecheck (run before finishing)

## Rules

- Work on a branch off `dev`; PRs target `dev`, never `main`.
- Don't commit `android/` or `ios/` – they are generated by `expo prebuild`.
- Don't add dependencies unless necessary; use `npx expo install` so versions match the Expo SDK.
- Keep the app offline: no network calls, analytics, or tracking (see `PRIVACY.md`).

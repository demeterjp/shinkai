# Shinkai (深海)

A mobile app that trains you to type Japanese kana on the phone flick keyboard, until it becomes automatic.

</div>

---

## Features

- Built-in flick keyboard: tap for the main character, swipe for the others
- Hiragana and Katakana
- Step-by-step guide to the keyboard
- Rounds of 10 random characters or all of them
- Review mistakes: practice the characters you got wrong
- Works offline, no account needed

---

## Built With

- Expo (React Native)
- TypeScript
- Expo Router
- AsyncStorage
- expo-linear-gradient

---

## Getting Started

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go.
